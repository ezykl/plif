# Frontend Design — Intentional Product UI

## Core Principles

1. **Lead with the Interactive Subject**:
   - For an interactive flipbook studio, the **Flipbook itself** is the hero. Users should immediately see and interact with the dual-page book at full stage height without scrolling past forms, banners, or multi-step wizard chrome.
2. **Avoid AI-Generated Template Tells**:
   - Do not put tracked-out ALL-CAPS eyebrow labels above every heading (`PLIF FLIPBOOK STUDIO • MAGAZINE EDITION`).
   - Do not clutter the screen with meta strings joined by middle dots (`12 sample pages • Standalone cover • Theme: Magazine • LTR`).
   - Do not use numbered wizard steps (`1. Upload › 2. Arrange & Style › 3. Preview & Publish`) when the user is working in a live, non-linear interactive studio where they can drop a PDF, switch styles, and export in one click.
3. **Plain, Honest Copywriting**:
   - Write from the user's perspective using plain verbs ("Drop PDF or images", "Export HTML", "Pages", "Chapters").
   - Never display misleading embed snippets with broken/unhosted URLs. Focus on what actually works 100% client-side and offline.
4. **Restraint**:
   - Spend visual boldness on the publication stage and realistic page turns. Keep the surrounding studio toolbar quiet, modern, and effortless to use.
